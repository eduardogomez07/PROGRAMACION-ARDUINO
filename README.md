# PROGRAMACION-ARDUINO
Programación desde Cero  Repositorio educativo con ejemplos progresivos de programación para Arduino.
El objetivo es aprender programación y electrónica mediante proyectos prácticos,
comenzando desde conceptos básicos y avanzando progresivamente hacia sistemas
automatizados.

## 📚 Contenidos

| Nº | Proyecto | Conceptos principales |
|---|---|---|
| 01 | Parpadeo de LED | `pinMode()`, `digitalWrite()`, `delay()` |
| 02 | LED con botón | Entradas digitales, `digitalRead()` |
| 03 | Semáforo | Secuencias, tiempos y salidas digitales |
| 04 | Potenciómetro + LED | Entradas analógicas, `analogRead()` |
| 05 | Sensor de luz | LDR, condiciones `if` |
| 06 | Sensor de temperatura | Sensor, variables y monitor serial |
| 07 | Sensor ultrasónico | Distancia, cálculo y condiciones |
| 08 | Servomotor | Librería Servo y control de posición |
| 09 | Control de motor | PWM y control de velocidad |
| 10 | Estación automática | Proyecto integrador |

## 🚀 Cómo utilizar el repositorio

1. Instalar Arduino IDE.
2. Clonar o descargar este repositorio.
3. Abrir la carpeta correspondiente.
4. Abrir el archivo `.ino`.
5. Conectar Arduino.
6. Seleccionar la placa.
7. Seleccionar el puerto COM.
8. Compilar.
9. Subir el programa.
